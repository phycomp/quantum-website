## 論文摘要

Quixer 是一種新型量子 Transformer 模型，利用 Linear Combination of Unitaries (LCU) 和 Quantum Singular Value Transform (QSVT) 作為建構塊。Quixer 透過準備 token 的疊加態並對此混合應用可訓練的非線性變換。這是第一個應用於實際語言建模任務的量子 Transformer 模型，結果與等效的古典基線模型競爭。

## 核心概念

### Quixer 架構
- **Unitary Token Embedding**: 將 token 嵌入轉換為量子態
- **LCU Mixing**: Linear Combination of Unitaries 混合 token 資訊
- **QSVT**: Quantum Singular Value Transform 應用非線性變換
- **Feed-Forward**: 量子前饋網路
- **Measurement**: 讀取量子態並古典處理

### 量子原語
- **LCU (Linear Combination of Unitaries)**: 準備單位矩陣的線性組合
- **QSVT (Quantum Singular Value Transform)**: 量子奇異值變換，應用多項式
- **PQC (Parameterized Quantum Circuit)**: 參數化量子電路

### 關鍵結果
- 第一個量子 Transformer 應用於實際語言建模任務
- 在 Penn Treebank 數據集上結果與古典基線競爭
- 提供量子硬體資源估算
- 開源古典模擬實現
