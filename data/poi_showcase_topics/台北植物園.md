# POI Showcase — 台北植物園

## 景點資訊

### 台北植物園 (Taipei Botanical Garden)

- **地址**：台北市中正區南海路53號
- **開放時間**：每日 5:30-20:00 (免費入園)
- **特色**：都市中的植物園，擁有 2,000+ 種植物，荷花池、棕櫚大道、蘭花園
- **最佳季節**：春季 (荷花、櫻花)、夏季 (荷花池)

## 交通路線 (MRT + 公車 + 步行)

### 路線 1：MRT 小南門站 (推薦)
- **MRT 松山新店線** → 小南門站 3 號出口
- **步行**：沿博愛路步行 5-8 分鐘至和平西路入口
- **總時間**：約 10-15 分鐘 (含步行)

### 路線 2：公車 (植物園站)
- **公車**：1, 242, 568, 624, 907, 藍28, 和平幹線
- **下車站**：植物園站 → 步行至和平西路入口
- **總時間**：約 15-20 分鐘

### 路線 3：公車 (三元街口站)
- **公車**：204, 630
- **下車站**：三元街口站 → 步行至和平西路入口
- **總時間**：約 15-20 分鐘

### 路線 4：公車 (建國中學站)
- **公車**：0東, 3, 238, 239, 243, 248, 262, 304, 603
- **下車站**：建國中學站 → 步行至植物園
- **總時間**：約 20-25 分鐘

### 蓮德品素天地 詳細資訊

- **地址**：台北市中正區寧波西街82號
- **電話**：02-23926208
- **營業時間**：07:30-10:00 (早餐)、11:00-14:00 (午餐)、17:00-21:00 (晚餐)
- **交通**：MRT 中正紀念堂站 2 號出口步行 5 分鐘
- **特色**：
  - 歐風裝潢，中西式料理
  - 提供火鍋、義大利麵、焗烤、燉飯、炒飯、拉麵
  - 全素或奶素餐點，由天然食材料理
  - 提供早餐、午餐、晚餐、便當外送
  - 單點 NT$99 起，CP 值高
  - 曾獲「豐蔬食 FVT 評鑑指南」一星殊榮
- **評價**：⭐⭐⭐⭐⭐ (Google 4.86 星，TripAdvisor 高評價)
- **Uber Eats**：可外送

### 交通路線：植物園 → 蓮德品素天地
- **MRT**：小南門站 → 中正紀念堂站 (1 站) → 2 號出口步行 5 分鐘
- **步行**：植物園 → 南海路 → 羅斯福路 → 寧波西街 (約 1.2 km, 15 分鐘)
- **公車**：植物園站 → 中正紀念堂站 (公車 1, 242 等)

### 交通路線：植物園 → 禾甲蒸豆腐食堂
- **步行**：植物園 → 中華路 → 禾甲蒸豆腐食堂
- **距離**：約 800 公尺，步行 10 分鐘

### 交通路線：植物園 → 蕃薯藤自然食堂
- **步行**：植物園和平西路入口 → 南海路 → 蕃薯藤自然食堂 (5樓)
- **距離**：約 200 公尺，步行 3 分鐘
