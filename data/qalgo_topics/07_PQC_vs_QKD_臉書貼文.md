# Facebook 貼文：PQC vs QKD

## 貼文內容

⚖️ PQC vs QKD：兩條不同的量子安全防禦路線

| 特性 | PQC（後量子密碼學） | QKD（量子金鑰分發） |
|------|-------------------|-------------------|
| 原理 | 數學演算法 | 量子力學物理定律 |
| 基礎設施 | 軟體升級 | 專用量子硬體、光纖 |
| 安全性 | 計算複雜度假設 | 資訊理論安全（無條件） |
| 距離限制 | 無 | ~100-200 km |
| 成本 | 低（軟體更新） | 高（專用硬體） |
| 部署時間 | 1-3 年 | 3-5 年 |

混合策略：
• 短期：QKD 保護關鍵金鑰分發，PQC 保護一般資料傳輸
• 長期：逐步過渡至全量子網路

選擇指南：
• 一般企業 → 優先 PQC（成本低、部署快）
• 政府/軍事/金融骨幹 → PQC + QKD 混合
• 高機密通訊 → QKD（資訊理論安全）
