```
│                         點加法幾何原理                               │
├──────────────────────────────────────────────────────────────────────┤

│      y                                    y                          │
│      ↑                                    ↑                          │
│      │     Q                              │      · 2P                │
│      │    /                               │     /                    │

│      │  /                                 │   /                      │
│      │ · P                                │  · P                     │
│      │/                                   │ /                        │
│      └────────┬──→ x                      └────────┬──→ x            │
│               │                                     │                │
│              R（延長線交點）                        切線交點         │
│  規則：過P、Q兩點的直線與曲線交於第三點R'，R為R'關於x軸的對稱點      │
```

### 2.2 代數推導（點加法公式）

```
┌──────────────────────────────────────────────────┐
│                  點加法公式推導過程              │
│已知 P = (x₁, y₁) Q = (x₂, y₂) 求R=P+Q=(x₃, y₃)   │
│Step 1: 計算斜率 m（連線斜率或切線斜率）          │
│      ⎧ (y₂ - y₁)(x₂ - x₁)⁻¹ mod p 若 P ≠ Q 點加  │
│  m = ⎨                                           │
│      ⎩ (3x₁² + a)(2y₁)⁻¹  mod p  若 P = Q  倍點  │
│Step 2: 求直線與曲線交點                          │
│  直線方程：y = m(x - x₁) + y₁                    │
│  代入曲線：y² = x³ + ax + b                      │
│  [m(x - x₁) + y₁]² = x³ + ax + b                 │
│  展開後為三次方程：x³ - m²x² + ... = 0           │
│  已知兩根 x₁, x₂，由韋達定理：x₁ + x₂ + x₃ = m²  │
│Step 3: 求R的坐標                                 │
│  x₃ = m² - x₁ - x₂  (mod p)                      │
│  y₃ = m(x₁ - x₃) - y₁  (mod p) 對稱點，y坐標取負 │
│┌────────────────────────────────────────────────┐│
││ 最終 x₃ = (m² - x₁ - x₂) mod p                 ││
││ 公式 y₃ = (m(x₁ - x₃) - y₁) mod p              ││
│└────────────────────────────────────────────────┘│
└──────────────────────────────────────────────────┘
```

## 三、標量乘法與離散對數問題

### 3.1 標量乘法（Scalar Multiplication）

```
┌────────────────────────────────────────────────────────────┐
│               標量乘法：k × P = Q                          │
│定義：k × P = P + P + ... + P  （k次點加）                  │
│計算方法：雙倍-加法算法（Double-and-Add）                   │
│示例：計算 13 × P                                           │
│  13 = 1101₂（二進制）                                      │
│  初始化：Q = ∞（無窮遠點，單位元）                         │
│          R = P                                             │
│  位1（最低位）：1    Q = Q + R = P        R = 2R = 2P      │
│  位2：          0    Q = Q = P            R = 2R = 4P      │
│  位3：          1    Q = Q + R = P + 4P = 5P   R = 2R = 8P │
│  位4（最高位）：1    Q = Q + R = 5P + 8P = 13P R = 2R = 16P│
│  結果：Q = 13P                                             │
│時間複雜度：O(log k) 次點加運算                             │
└────────────────────────────────────────────────────────────┘
```

### 3.2 橢圓曲線離散對數問題（ECDLP）

```
┌─────────────────────────────────────────────────────┐
│            安全性基礎：ECDLP                        │
│ 正向計算（容易）：          逆向計算（困難）：      │
│      私鑰 k                      公鑰 Q = (x, y)    │
│        ↓                                ↓           │
│     k × G = Q                  求 k = ?             │
│  （雙倍-加法算法）              （無已知多項式算法）│
│     O(log k)                    O(√n) Pollard's rho │
│┌───────────────────────────────────────────────────┐│
││ 已知：G（基點），Q = kG（公鑰）                   ││
││ 求：k（私鑰）                                     ││
││ 最佳已知算法：                                    ││
││ • Pollard's rho 算法：O(√n)，其中 n 是基點的階    ││
││ • 對於 n ≈ 2²⁵⁶，需要 ≈ 2¹²⁸ 次運算               ││
││ • 以目前超級計算機速度，需要 >> 宇宙年齡          ││
││ ⚠️ 量子威脅：Shor 算法可在 O((log n)³) 時間內破解 ││
│└───────────────────────────────────────────────────┘│
└─────────────────────────────────────────────────────┘
```

## 四、ECC密鑰生成與加密系統

### 4.1 密鑰生成協議

```
┌────────────────────────────────────────────────────────────────┐
│                    ECC密鑰生成流程                             │
│  公開參數（域參數）：                                          │
│  ┌────────────────────────────────────────────────────────────┐│
│  │  • 素數 p（定義有限域 𝔽ₚ）                                 ││
│  │  • 曲線係數 a, b                                           ││
│  │  • 基點 G = (x_G, y_G)（生成元，階為大素數 n）             ││
│  │  • 基點的階 n（n × G = ∞）                                 ││
│  └────────────────────────────────────────────────────────────┘│
│  用戶A（Alice）              用戶B（Bob）                      │
│  隨機選擇：                    隨機選擇：                      │
│  k_A ∈ [1, n-1]               k_B ∈ [1, n-1]                   │
│       ↓                            ↓                           │
│  計算公鑰：                    計算公鑰：                      │
│  Q_A = k_A × G                 Q_B = k_B × G                   │
│       ↓                            ↓                           │
│  公開 Q_A  ────────────────→  保留私鑰 k_B                     │
│  保留私鑰 k_A  ←────────────  公開 Q_B                         │
│  共享密鑰計算：                                                │
│  Alice 計算：S = k_A × Q_B = k_A × (k_B × G) = (k_A × k_B) × G │
│  Bob 計算：  S = k_B × Q_A = k_B × (k_A × G) = (k_B × k_A) × G │
│  ∴ 雙方得到相同共享密鑰點 S                                    │
└────────────────────────────────────────────────────────────────┘
```

### 4.2 ECIES加密方案（橢圓曲線集成加密標準）

```
┌──────────────────────────────────────────────────────────┐
│                  ECIES加密/解密流程                      │
│加密Alice→Bob Alice擁有 Bob的公鑰 Q_B = k_B × G           │
│Step 1: 生成臨時密鑰對                                    │
│  隨機選擇 r ∈ [1, n-1]                                   │
│  計算 R = r × G  （臨時公鑰，隨密文發送）                │
│Step 2: 計算共享密鑰                                      │
│  S = r × Q_B = r × (k_B × G) = (r × k_B) × G = (x_S, y_S)│
│Step 3: 密鑰派生（KDF）                                   │
│  k_enc || k_mac = KDF(x_S || R || Q_B)                   │
│  （使用SHA-256等哈希函數派生對稱加密密鑰和MAC密鑰）      │
│Step 4: 對稱加密                                          │
│  c = AES-GCM(k_enc, m)  （加密明文m）                    │
│Step 5: 計算認證標籤                                      │
│  tag = MAC(k_mac, c || R)                                │
│發送密文：(R, c, tag)                                     │
│解密Bob Bob收到：(R, c, tag)，擁有私鑰 k_B                │
│Step 1: 恢復共享密鑰                                      │
│  S' = k_B × R = k_B × (r × G) = (k_B × r) × G = S        │
│  （僅Bob能計算，因為只有他知道k_B）                      │
│Step 2: 派生相同密鑰                                      │
│  k_enc || k_mac = KDF(x_S' || R || Q_B)  （與Alice相同） │
│Step 3: 驗證完整性                                        │
│  驗證 tag == MAC(k_mac, c || R)                          │
│Step 4: 解密                                              │
│  m = AES-GCM⁻¹(k_enc, c)                                 │
└──────────────────────────────────────────────────────────┘
```

## 五、數字簽名算法（ECDSA）

### 5.1 簽名與驗證流程

```
┌────────────────────────────────────────────────────────┐
│                ECDSA數字簽名算法                       │
│簽名生成（擁有私鑰k，公鑰Q = kG）：                     │
│輸入：消息m，私鑰k，基點G（階n）                        │
│Step 1: 計算消息哈希                                    │
│  e = HASH(m)  （如SHA-256，取左邊n位）                 │
│Step 2: 生成隨機數                                      │
│  選擇隨機數 d ∈ [1, n-1]                               │
│  計算 (x₁, y₁) = d × G                                 │
│  r = x₁ mod n    （若r=0則重選d）                      │
│Step 3: 計算s                                           │
│  s = d⁻¹(e + k·r) mod n    （若s=0則重選d）            │
│輸出簽名：(r, s)                                        │
│                                                        │
│簽名驗證（擁有公鑰Q，消息m，簽名(r,s)）：               │
│Step 1: 驗證r, s範圍                                    │
│  檢查 1 ≤ r, s ≤ n-1                                   │
│Step 2: 計算哈希和輔助值                                │
│  e = HASH(m)                                           │
│  w = s⁻¹ mod n                                         │
│  u₁ = e·w mod n                                        │
│  u₂ = r·w mod n                                        │
│Step 3: 計算曲線點                                      │
│  (x₂, y₂) = u₁ × G + u₂ × Q                            │
│Step 4: 驗證                                            │
│  檢查 r ≡ x₂ (mod n)  若成立則簽名有效                 │
│u₁G + u₂Q = ewG + rw(kG) = (e + rk)wG = (e + rk)s⁻¹d⁻¹G │
│正確性證明= (e + rk)(e + rk)⁻¹dG = dG = (x₁, y₁)        │
│∴ x₂ = x₁，故 r ≡ x₂ (mod n)                            │
└────────────────────────────────────────────────────────┘
```

## 六、量子計算威脅與數學分析

### 6.1 Shor算法對ECC的攻擊

```
┌───────────────────────────────────────────────────────────────────┐
│                 Shor算法破解ECC的數學原理                         │
│核心思想：將ECDLP轉化為隱藏子群問題（HSP），用量子傅立葉變換求解   │
│Step 1: 構造週期函數                                               │
│  定義函數 f: ℤ × ℤ → 橢圓曲線點群                                 │
│  f(a, b) = aG + bQ = aG + b(kG) = (a + bk)G                       │
│  觀察：f(a, b) = f(a', b')  當且僅當  (a - a') ≡ k(b' - b) (mod n)│
│  ⇒ 函數f的週期與私鑰k相關！                                       │
│Step 2: 量子疊加態構造                                             │
│  製備量子態：|Ψ⟩ = 1/√(N²) Σₐ Σᵦ |a⟩|b⟩|f(a,b)⟩                   │
│  測量第三寄存器（函數值）後，前兩寄存器塌縮為：                   │
│  |Ψ'⟩ = 1/√N Σⱼ |a₀ + j·t⟩|b₀ + j·s⟩                              │
│  其中 (t, s) 是週期格子的基向量，滿足 t ≡ -ks (mod n)             │
│Step 3: 量子傅立葉變換提取週期                                     │
│  對前兩寄存器應用QFTₙ：                                           │
│  QFTₙ|x⟩ = 1/√n Σᵧ e^(2πixy/n) |y⟩                                │
│  測量後以高概率得到滿足以下條件的 (c, d)：                        │
│  ct + ds ≡ 0 (mod n)                                              │
│  代入 t ≡ -ks (mod n)：                                           │
│  c(-ks) + ds ≡ 0  ⇒  s(d - ck) ≡ 0 (mod n)                        │
│  若 s ≢ 0 (mod n)，則 d ≡ ck (mod n)，即 k ≡ d·c⁻¹ (mod n)        │
│Step 4: 計算私鑰                                                   │
│  k = d · c⁻¹ mod n                                                │
│時間複雜度：O((log n)³) 量子門操作                                 │
│空間複雜度：O(log n) 量子比特                                      │
│對於256位ECC 約需2048邏輯量子比特 考慮糾錯後約需百萬級物理量子比特 │
└───────────────────────────────────────────────────────────────────┘
```

## 七、總結：ECC安全性的數學基礎

```
┌─────────────────────────────────────────────────────────────────┐
│                        ECC安全性層次結構                        │
│   ┌────────────────────────────────────────────────────────────┐│
│   │  應用層：ECIES加密、ECDSA簽名、ECDH密鑰交換                ││
│   │  依賴於 → 標量乘法 kP 的單向性                             ││
│   │  依賴於 → 點加法群運算的封閉性與結合律                     ││

│   │  依賴於 → 大素數p的選擇（避免p-1光滑、超奇異曲線等弱曲線） ││

└─────────────────────────────────────────────────────────────────┘
```

以上推導展示了ECC從基礎代數結構到實際密碼學應用的完整數學體系。理解這些原理對於評估量子計算時代的密碼學遷移策略至關重要。
