## 一、量子金鑰分發（QKD）核心概念

QKD 是利用**量子力學原理**實現安全通訊的技術，其核心優勢在於：

| 特性 | 說明 |
|------|------|
| **資訊理論安全性** | 安全性基於物理定律，非計算複雜度假設 |
| **竊聽可檢測** | 任何竊聽行為必然留下可檢測痕跡 |
| **一次性密碼本（OTP）** | 產生完全隨機的金鑰，實現完美保密 |

## 二、BB84 協議：量子態編碼的奠基者

### 物理機制

**發明者**：Charles Bennett 與 Gilles Brassard（1984年）

**核心原理**：利用光子的**偏振態**作為量子位元載體

```
編碼方案：
┌───────────┬────────┬────────┐
│    基底   │ 位元 0 │ 位元 1 │
├───────────┼────────┼────────┤
│直線基底(+)│ 水平 ─ │ 垂直 │ │
│對角基底(×)│ 左下↙  │ 右下↘  │
└───────────┴────────┴────────┘
```

**運作流程**：

1. **傳送端（Alice）**：隨機選擇基底（+ 或 ×）編碼位元，發送光子
2. **接收端（Bob）**：隨機選擇基底測量
3. **公開比對**：透過經典通道比對基底選擇，保留相同基底的結果
4. **誤差檢測**：抽樣比對部分位元，計算量子位元錯誤率（QBER）
   - QBER > 11%：判定存在竊聽，捨棄金鑰
   - QBER < 11%：進行錯誤校正與隱私放大

**安全性基礎**：

- **測不準原理**：無法同時精確測量非正交量子態
- **不可克隆定理**：無法完美複製未知量子態

## 三、E91 協議：量子糾纏的典範

### 物理機制

**發明者**：Artur Ekert（1991年）

**核心原理**：利用**量子糾纏對**（EPR pair）的關聯性

```
量子糾纏態（Bell State）：
|Ψ⁻⟩ = (|01⟩ - |10⟩)/√2

特性：無論距離多遠，測量結果瞬間關聯
```

**運作流程**：

1. **糾纏源產生**：中央節點產生糾纏光子對，分別發送給 Alice 與 Bob
2. **隨機測量**：雙方隨機選擇三個測量角度（0°, 45°, 90°）
3. **Bell 不等式檢驗**：驗證糾纏關聯性，確保無局域隱變數
   - 違反 Bell 不等式 → 確認量子糾纏存在
   - 滿足 Bell 不等式 → 可能存在竊聽或系統問題
4. **金鑰萃取**：使用相同測量角度的結果產生金鑰

**BB84 vs E91 比較**：

| 特性 | BB84 | E91 |
|------|------|-----|
| **量子資源** | 單光子態 | 糾纏光子對 |
| **光源位置** | 傳送端 | 中央節點/第三方 |
| **安全性驗證** | 誤差率檢測 | Bell 不等式違反 |
| **設備需求** | 單光子源、偏振調製 | 糾纏源、符合計數 |
| **優勢** | 技術成熟、距離遠 | 可擴展至量子網路 |

## 六、創新商業模式建議

### 1. **Quantum Fabric as a Service (QFaaS)**

- 提供多通道 QKD 硬體的雲端租賃服務
- 按金鑰位元數或通道數計費
- 目標客戶：金融機構、雲端服務商

### 2. **混合量子-古典網路整合**

- 與電信業者合作，在現有 DWDM 網路中嵌入量子通道
- 利用 **WDM-QKD**  技術，同時支援 O-band (1310nm) 與 C-band (1550nm)
- 降低部署成本，提升頻譜效率

### 3. **晶片級 QKD 模組供應**

- 開發 **矽光子整合 QKD 晶片**，包含光源、調變器、偵測器
- 供應給通訊設備商整合至路由器、交換器
- 參考模式：Intel 矽光子收發器

### 4. **量子安全認證服務**

- 提供 QKD 設備的**安全性認證**與**滲透測試**
- 建立量子金鑰的**生命週期管理**與**稽核軌跡**
- 符合金融與政府合規要求
