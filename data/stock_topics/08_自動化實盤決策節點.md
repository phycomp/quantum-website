## 一、目標定義（決策節點 #1）

> 用永豐 Shioaji 模擬環境，把「5 分 K 波段策略 → 風控 → 下單 → 成交回報 → 重啟復原 → 盤後對帳」整條鏈路，在**不碰真錢**的前提下連續跑通 **5 個交易日**。

**不是**在追求獲利策略。這一階段的成功標準是「系統正確」，不是「策略賺錢」。

## 三、被否決的選項（留給未來的自己）

| 否決項 | 原因 |
|---|---|
| 直接實盤小額 | 沒風控、沒重啟復原、沒成交確認 → 重複下單或幽靈持倉 |
| tick 級 5/10 筆均線 | 秒級翻轉、來回成本 0.47% 起跳，期望值必為負；tick 噪音無統計意義 |
| 另開全新專案 | 需重寫下載/指標/回測，工期 3–5 倍，失去 `展示/` 已驗證部分 |

## 五、實盤上線前三大隱形坑（`注意事項.md`）

1. **模擬盤測試**：絕不把剛寫好的策略直接丟實盤 — 先用 VN.PY 內建 `Sizer`（手動下單）看一週，或永豐**模擬環境（Simulation Mode）** API 測試，確認訊號與下單動作完全一致。
2. **滑價與流動性**：回測假設成交在收盤價；實盤市價/限價單下達時市場已跳動 — 加**滑價保護**（買入限價 = 目前價格 + 2 檔）。
3. **網路斷線與例外**：台股 09:00 開盤瞬間爆量、API 斷線是家常便飯 — 實作 `on_disconnect` 自動重連 + 每日開盤前重啟系統清快取。

（Shioaji 範例：事件驅動架構 — 初始化 → 登入與憑證啟用 → 訂閱 Tick → 均線交叉計算 → 自動下單；需先向券商申請 API 權限並放置 .pfx 憑證。）
