## 一、金融資料獲取 API

| 工具 | 市場 | 說明 |
|---|---|---|
| **FinMind** | 台股為主 | 台灣開源金融大數據 API：台股、美股、期權、財報、籌碼面等 50+ 種數據 |
| **yfinance** | 美股/全球 | Yahoo Finance API 下載歷史市值：K 線、除權息、基本面；全球主流市場 |
| **TuShare** | A 股為主 | 免費金融大數據接口，含股票、基金、期貨、宏觀經濟（部分全球數據） |

## 二、量化回測與策略框架

| 框架 | 定位 |
|---|---|
| **backtrader** | GitHub 最受歡迎的 Python 回測框架之一：多商品回測、多指標分析、內建圖表輸出 |
| **vnpy** | 開源量化交易平台開發框架：底層接口 + 上層策略（CTP 期貨、證券 API），從回測一路到實盤 |
| **pyfolio** | 投資組合性能與風險分析：一鍵生成夏普比率（Sharpe）、最大回撤（Max Drawdown）等量化必備圖表 |

## 三、台灣市場特定

- **TEJAPI_Python_Medium_Quant**：台灣經濟新報（TEJ）維護的範例庫 — 定期定額、技術分析、機器學習預測、籌碼分析回測範例。
- 深入探索：GitHub 的 Market Data API Topics 頁面。

## 四、核心開發流程

```
資料獲取 → 策略撰寫與回測 → 風險與績效評估
（yfinance + pandas + backtrader/pyfolio 為最小可行組合）
```

**入門範例**（來源檔）：yfinance（取數據）+ pandas 撰寫**均線交叉策略**（Moving Average Crossover）+ pyfolio（風險分析）。
