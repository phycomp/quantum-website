## 一、平台定位

**Quant Investment Platform** — 針對台灣地區高資產投資人的 Python 量化投資系統，**無需 API Token 即可使用**（免費數據源）。

投資者 Profile：資金 1,000 萬+、經驗進階（7 年+）、風險承受極高、時間框架 1–3 年短中期、45–55 歲資產鞏固期。

## 二、五層模組架構（8,279 行）

```
quant_investment_platform/
├── config/settings.py              # 全局配置（BrokerConfig 等）
├── data/
│   ├── free_data_source.py         # ★ 免費數據源（yfinance）
│   ├── download_all.py             # ★ 一鍵下載腳本
│   ├── fetcher.py                  # 數據抓取接口（含台灣證交所）
│   └── processor.py                # 技術指標計算
├── research/
│   ├── factor_model.py             # 多因子選股模型（491 行）
│   ├── factor_optimizer.py         # 因子權重優化
│   └── backtest.py                 # 回測引擎
├── strategies/
│   ├── taiwan_swing.py             # 台股波段策略（TWSwingScanner 標的掃描器）
│   ├── us_swing.py                 # 美股波段策略（USSwingScanner）
│   └── options_spread.py           # 選擇權價差策略
├── execution/
│   ├── broker_fubon.py             # 富邦證券 API
│   ├── broker_sinotrade.py         # 永豐證券 API
│   ├── broker_ib_full.py           # Interactive Brokers
│   └── order_manager.py           # 智能訂單路由 + RiskGate 風控閘道
├── risk/
│   └── metrics.py                  # VaR、夏普、最大回撤、Beta、相關性矩陣（364 行）
└── examples/demo_backtest.py       # 回測示範
```

另有 Streamlit dashboard（`dashboard/app.py` 36,327 bytes 巢狀 zip `quant_investment_platform_streamlit.zip`）與 `回測Util.py`/`回測UtilII.py`。

## 三、快速開始（無需 API Token）

```bash
pip install yfinance pandas numpy talib-binary backtrader
python data/download_all.py      # 一鍵下載免費歷史數據
python examples/demo_backtest.py # 回測示範
python research/factor_model.py  # 多因子選股
```

**下載內容**：台股藍籌 30 檔（5 年日線）、台股熱門 ETF 10 檔（5 年）、加權指數 ^TWII（10 年）、美股七巨頭（5 年）、槓桿/反向 ETF（3 年）、美股指數（10 年）。

## 四、數據源

| 來源 | 費用 | 限制 | 入口 |
|------|------|------|------|
| **yfinance** | 免費 | 頻繁抓取可能暫時封 IP（分批 + `time.sleep(0.5)`） | `data/free_data_source.py` |
| **台灣證交所** | 免費 | 有頻率限制 | `data/fetcher.py` |
| **FRED** | 免費 | 僅總經數據 | `download_fred_data()` |

> 免費數據延遲 15–30 分鐘，僅適合回測與日內策略規劃。

## 五、多因子選股模型（`research/factor_model.py`）

| 因子 | 權重 | 內容 |
|------|------|------|
| 動能 | 30% | 價格動能、成交量動能、營收/籌碼動能 |
| 品質 | 25% | ROE、負債比、獲利穩定性、財務健康度 |
| 成長 | 25% | 營收成長、獲利成長、EPS 成長 |
| 估值 | 20% | 相對 PE/PB、52 週位置 |

## 六、策略模組

- **台股/美股波段**：`TWSwingScanner`/`USSwingScanner` 標的掃描器（分鐘/日線波段 — 決策節點 D4：台股現貨來回成本約 0.47%，tick 級翻倉數學上不可能獲利）。
- **選擇權價差**（`options_spread.py`，針對高資產 Profile）：Bear Put Spread（溫和看空/避險）、Ratio Spread（非對稱風險報酬，高確信度時用）等；**所有策略均設停損**。

## 七、券商串接（可選，實盤時填入）

```python
# config/settings.py
BROKER = BrokerConfig(
    TW_BROKER="fubon",           # 或 "sinotrade"
    TW_API_KEY="your_key",
    TW_API_SECRET="your_secret",
    IB_HOST="127.0.0.1", IB_PORT=7497,
    PAPER_TRADING=False,          # 預設 True；確認策略有效後再切實盤
)
```

支援：富邦、永豐（Shioaji）、Interactive Brokers；`order_manager.py` 的 **RiskGate** 在下單前檢查：部位上限、停損條件、流動性、風險集中度。

## 八、資產配置與風控參數（極積極進攻型）

| 類別 | 比例 |
|------|------|
| 權益類 | 75%（台股個股 35% + 基金 15% + ETF 10% + 美股 15%） |
| 衍生性/槓桿 | 20%（權證 + 期貨選擇權 + 槓桿 ETF） |
| 現金 | 5% |

風控紅線：單一標的 ≤ 10%；衍生性工具合計 ≤ 20%；硬停損 -15%；組合最大回撤 25%（強制減碼）；**絕對虧損上限 30%（資產不低於 700 萬）**。

> ⚠️ 資產鞏固期底線：即使極高風險偏好，也建議設絕對虧損上限（70% 資產保護線）— 與 `04_投資心法.md` Klarman「避免永久性資本損失」同源。
