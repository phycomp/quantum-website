# physim — 平台架構與核心

## 本地來源

- `README.md`（專案總覽、架構、資料流）
- `docs/project_structure.md`
- `physim/contracts.py`, `physim/service.py`, `physim/core/*`

## 核心內容

- 單一套件 `physim/`，bottom-up：純 NumPy/SciPy 模型與場景描述 → matplotlib/pyvista/Qiskit 渲染 → Streamlit/panel/CLI。
- `physim/core`：ParamSpec/ParamSet、Preset、Scene2D/Scene3D、Model 協定、registry、cache。
- `physim/domains/*`：每個 domain = `numerics.py` + `models.py` + `__init__.py`；numerics 不 import UI/繪圖庫。
- `physim/service.py`：唯讀服務層 `list/search/describe/presets/resolve/summary/render`。
- `physim/contracts.py`：pydantic 契約（ModelInfo/SummaryResult/RenderResult/SvgResult…），UI/CLI/外部共用。
- 資料流：`ParamSpec/ParamSet → BaseModel.frame() → numerics.py → Scene2D/Scene3D → render_frame()/render_frames(renderer=...) → PNG/SVG → HTML/GIF/panel/Streamlit`。
- 新增模型只需：numerics 函式 → BaseModel 子類 → ModelMeta/ParamSpec/Preset → frame() → register()；UI/CLI/service 自動列出。
