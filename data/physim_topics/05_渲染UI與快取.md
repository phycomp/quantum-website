# physim — 渲染、UI 與快取

## 本地來源

- `README.md`（UI、深連結、匯出、快取與環境變數）

## 核心內容

- 2D：matplotlib Agg → PNG；SVG 必支援。
- 3D：pyvista 離屏渲染 → PNG；失敗時退回 matplotlib 3D；`PHYSIM_STRICT_3D=1` 直接報錯。
- 電路域：Qiskit 官方 Bloch multivector + 電路圖；pyvista Bloch 球雙 renderer。
- 播放器：內建單檔 HTML、GIF、panel、Streamlit；HTML 有播放/暫停/逐幀/速度/循環/單幀下載。
- 匯出：SVG、摘要 CSV/JSON、參數 JSON、HTML 播放器、GIF。
- 深連結：`?model=...&m=...&t=...&renderer=...&frame=...`；優先序 URL → session → 預設；param > preset > default。
- Streamlit 非主執行緒 3D 隔離到 worker process，避開 VTK segfault。
- 快取：以「模型 + 參數 digest + 幀 + dpi + 渲染後端」為 key；命中 ~0.0002–0.0004s。
- 環境變數：`PHYSIM_CACHE`、`PHYSIM_STRICT_3D`、`PHYSIM_3D_INPROCESS`。
