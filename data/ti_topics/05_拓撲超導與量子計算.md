> 本地來源：`拓撲/01拓撲絕緣超導體.md`、`拓撲/基礎/0超導vs絕緣體.md`

## 1. TI vs 拓撲超導體對照表（本地檔核心表）

| 特性 | 拓撲絕緣體 | 拓撲超導體 |
|------|-----------|-----------|
| 電子結構 | 體絕緣 + 受保護金屬表面態 | 超導能隙 + Majorana 零能模表面/邊緣 |
| 保護機制 | TRS（Kramers 簡併） | 拓撲保護的非阿貝爾統計 |
| 代表材料 | Bi₂Se₃、Bi₂Te₃、Sb₂Te₃ | FeTeₓSe₁ₓ、TI/s-wave SC 異質結 |
| 製備 | MBE / 剝離 / CVD / 塊材 | 異質結工程（Bi₂Se₃/NbSe₂）、摻雜、高壓、自組裝 |
| 成熟度 | 相對成熟 | 探索階段 |
| 穩定性 | 室溫穩定 | 多需極端條件 |
| 驗證 | ARPES + 輸運（方法完善） | 驗證困難（MZM 訊號有爭議史） |
| 應用 | 自旋電子學、傳感、熱電、（低溫傳輸線） | 拓撲量子位元（容錯）、無耗散邊緣電流 |

## 2. 實現拓撲超導的四條路（本地檔）

1. **異質結構工程**：TI 薄膜 + s-wave 超導體（Bi₂Se₃/NbSe₂、Bi₂Se₃/Nb）— 近鄰誘導配對 + 自旋-動量鎖定 → 有效 p-wave → **Majorana 零能模（MZM）** 建議方案
2. **摻雜調控**：CuₓBi₂Se₃（超導 T_c ~3.8 K，候選拓撲超導體）
3. **壓力調控**：高壓誘導拓撲相變 + 超導共存
4. **本征候選**：FeTe₀.₅₅Se₀.₄₅（拓撲能帶 + 超導，MZM 報導最多的平台之一）

## 3. 量子計算意義

- MZM = 電子「一半」的非阿貝爾準粒子 → 拓撲量子位元（braiding 操作受拓撲保護，局部噪聲免疫）
- 理論拓撲位元錯誤率可低於表面碼（surface code）平台約 1–2 個數量級
- 現實：MZM 的零偏移電導峰（zero-bias peak）證據多次爭議（早期 InSb 奈米線工作被撤銷）；鐵基超導渦旋 MZM 相對乾淨
