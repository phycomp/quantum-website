## 1. 指標定理路線（免 DFT 的快速預測）

**Atiyah-Singer 指標定理**在晶格系統的離散版本：

```
Ind(D) = dim ker D - dim ker D† = ∫_M Â(TM) ∧ ch(V)
```

- 解析指標（佔據態 − 空態數目差）= 拓撲指標（Berry 曲率積分 = Chern 數/Z₂）
- 對稱性指標理論（Symmetry Indicators）+ 拓撲量子化學（TQC）→ **只用空間群 + Wyckoff 位置 + 帶在不可約表示的佔據**即可判別拓撲性質
- 本地實作 `services/index_theorem_predictor.py`（`指標/快速預測.md`）：
  - 輸入 pymatgen Structure → SpacegroupAnalyzer 對稱性分解 → Wyckoff 位置 → 解析指標 → ms 級返回「原子絕緣體 vs 拓撲材料」
  - 後端 PostgreSQL（拓撲材料庫）
- 準確率：對多數空間群的絕緣體可給出完整判別；模糊帶（半金屬）需 fallback 到完整 DFT

## 2. DFT 路線（高精度确認）

`指標/dftTI.md`：
- Wannier 插值算 Berry 相位/Z₂/Wilson loop
- 雜化泛函修正帶隙（PBE 低估 ~50%）
- 表面態模擬（slab 模型）→ 對照 ARPES
- 成本：每材料 CPU 小時級 → 只適合候選確認，不適合百萬級掃描

## 4. 國際資料庫現況（2026-11-11 檢索）

| 資料庫 | 內容 | 入口 |
|--------|------|------|
| **TopoMat** | 高通量第一性原理篩選已知晶體的拓撲性質 | materialscloud.org/discover/topomat |
| **Topological Quantum Chemistry (TQC)** | Poledger/Vergniory 系，~90,000+ 材料的拓撲分類 | topology.mit.edu / materialscloud |
| **磁性拓撲材料庫** | Robredo et al. 2025（Sci. Adv. adv8780）：522 個新磁性拓撲材料；奠基於 Xu et al. 2020（Nature, cited 550+）磁性高通量計算 | science.org |
| Bi2Se3-type 資料庫 | 專注 3D TI 帶反轉材料 | 各文獻補充 |

- 趨勢共識：**「拓撲很常見」**（topological materials abundance）— 對稱性指標掃描顯示相當比例的已知絕緣體/半金屬帶非平凡拓撲；瓶頸在**帶隙品質與缺陷控制**，而非候選數量。
- 磁性拓撲是 2025–2026 擴充最快的子領域（高通量 AFM/FM 序掃描工作流已標準化）。
