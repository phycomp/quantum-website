## 1. Berry 相位與曲率（拓撲的語言）

### 1.1 三件套定義

| 量 | 定義 | 物理意義 |
|----|------|-----------|
| Berry 聯絡 | A_n(k) = i⟨u_nk\|∇_k\|u_nk⟩ | 動量空間的「向量勢」 |
| Berry 曲率 | Ω_n(k) = ∇_k × A_n(k) | 動量空間的「磁場」；規範不變 |
| Berry 相位 | γ = ∮ A·dk | 沿閉合迴路累積的幾何相位 |

- 能帶 n 的拓撲荷 = Berry 曲率在整個布里淵區（BZ）的積分：
  - **Chern 數（2D）**：C = (1/2π)∫_BZ Ω(k) d²k — 整數，破壞 TRS 才可能非零
  - **Z₂ 不變量（3D TRS 系統）**：簡化判據為「奇數個帶反轉 ↔ 非平凡」

### 1.2 拓撲相變機制（SOC 驅動能帶反轉）

```
三階段演化（Γ 點附近）：
  λ_SO 小：正規序  s 帶在下、p 帶在上 → 拓撲平凡 Z₂=0
      ↓ SOC 增大（或應變/壓力/組分調控）
  臨界點：能隙閉合（量子相變點，Berry 曲率集中爆發）
      ↓
  帶反轉：p 帶在下、s 帶在上 → 拓撲非平凡 Z₂=1
```

- 帶反轉發生後，體態必須在任意表面上「補償」拓撲荷 → **受拓撲保護的表面態**，其波函數在穿過表面時累積 **π 相位翻轉**（相位纏繞繞不動，故表面態無法被局域化去除）。
- 直觀圖像：Berry 曲率在 BZ 的「滲流」— 相變點是曲率從局域漲落變成宏觀流通的臨界點。

## 2. 時間反演對稱性（TRS）與 Kramers 簡併

- 時間反演算符（自旋 1/2）：Θ = -iσ_y K，滿足 **Θ² = -1**
- Kramers 定理：TRS 系統中，動量 k 與 -k 的態必須簡併 → **背向散射被禁止**（正反兩態自旋相反，非磁性雜質無法耦合）
- 這是 TI 表面態低耗散傳輸的根源：自旋-動量鎖定 + 背散射禁止 → 彈道傳輸
- TRS 破壞（磁性摻雜/磁性近鄰）→ 表面態打開能隙 → 量子反常霍爾（QAHE）平台（見子主題 02）

## 3. BHZ 模型（2D TI 的最小模型）

H(k) = ε(k)𝟙 + d(k)·σ（4×4，含自旋）

- d(k) = (A k_x, A k_y, M(k))，M(k) = M₀ - B k²（符號決定拓撲）
- **B ≠ 0 且 M₀/B > 0 → 帶反轉 → 拓撲非平凡**（量子自旋霍爾態）
- 能隙 = 2|M|（在 Γ 點）
- TRS 證明：Θ H(k) Θ⁻¹ = H(-k)，靠 A、M 皆為 k 的偶函數/適當矩陣結構成立
- 邊界解：拓撲區（M₀/B>0）在邊上必然出現螺旋邊態，態數 = Z₂ 不變量

## 4. 3D TI 表面態（Dirac 錐）

```
表面態色散：E(k) = ±ħ v_F |k|，v_F ≈ 5×10⁵ m/s（Bi₂Se₃ 家族）
體態能隙：~0.3 eV（Bi₂Se₃；實際塊材因缺陷常呈 n 型）
自旋繞 Dirac 點呈左手螺旋（自旋-動量鎖定）
```

- 奇數個 Dirac 錐 = Z₂ 非平凡的表面指紋（Bi₂Se₃: 1 個；拓撲晶體絕緣體靠晶體對稱保護，可有多個）
- ARPES（角分辨光電子能譜）是直接觀測表面 Dirac 錐與自旋紋理的標準工具。
