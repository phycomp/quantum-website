## 1. 控制方式

### 1.1 單量子閘

- **XY 操作**：微波脈衝經電容耦合，實現布洛赫球 X-Y 旋轉。
  - 驅動哈密頓量：\(H = -\frac{\hbar}{2}\omega\sigma_z + \Omega_x\cos(\omega_d t - \phi)\sigma_x\)
  - 相位 φ 控制旋轉軸、振幅 Ω 控制旋轉角度。
- **Z 操作**：Z 控制線注入電流到 SQUID 環，改變磁通調節頻率。

### 1.2 雙量子閘

- **耦合方式**：電容/電感耦合、磁通調控耦合器。
- **Transmon tunable coupler**：可調耦合強度。
- **C-shunt flux coupler**：更強 ZZ 抑制。

## 2. 串擾類型

### 2.1 磁通偏置串擾 (Flux Bias Crosstalk)

- DC 串擾：實際偏置電流變化，影響共振頻率/復位偏置。
- RF 串擾：微波控制信號洩漏（≤-20 dB，通常可忽略）。
- 對策：校準補償、脈衝序列校正。

### 2.2 測量串擾 (Measurement Crosstalk)

- 相位 Qubit：~20% 機率。
- 電容耦合導致測量一個 Qubit 的 |1⟩ 可能激發鄰居 |0⟩。
- 對策：精確控制測量脈衝時間重疊。

### 2.3 Readout SQUID Crosstalk

- 一個 SQUID 切換到電壓態可能觸發鄰居 SQUID。
- 對策：依次斜坡掃描各 SQUID 偏置。

### 2.4 ZZ 串擾 (Static ZZ)

- Qubit 間殘餘 \(ZZ\) 耦合，導致相位錯誤。
- Transmon：固定頻率架構下頻率擁擠加劇。
- Fluxonium：低頻自然隔離優異（< -60 dB 即使 32 鄰居）。
- Quarton：耦合可獨立調控。

## 3. 多鄰居效應

- **RSS 叠加（不相干）**：耦合隨 √N 增加。
- **最差情況（相干）**：耦合隨 N 線性增加。
- **共振效應**：頻率失諧 < 線寬時，串擾增強 Q 倍。
- **ColorDynamic 頻率分配**：避免共振。

## 4. 串擾抑制技術

| 技術 | 說明 | 效果 |
|---|---|---|
| Tunable coupler | 可調耦合強度 | ZZ ~1 kHz (fluxonium) |
| C-shunt flux coupler | 電容分流 flux coupler | 比 tunable transmon 更強抑制 |
| 頻率分配 (ColorDynamic) | 避免頻率碰撞 | 降低共振串擾 |
| Flip-Chip 3D | 物理分離 Qubit/控制線 | 減少電磁耦合 |
| 屏蔽/接地 | 良好接地設計 | 降低串擾 |

## 5. 模擬與驗證

- **DMRG**（IOP 2025-12）：密度矩陣重正化群模擬大規模 Qubit 晶格串擾。
- **結論**：Fluxonium + tunable transmon coupler 殘餘 ZZ ~1 kHz，IPR 較 transmon 高；但 capacitive loading 與頻率擁擠仍為挑戰。
