## 1. 傳統位元 vs 量子位元

| 比較項目 | 傳統位元 (Bit) | 量子位元 (Qubit) |
|---|---|---|
| 基本狀態 | 0 或 1（開關） | 0 與 1 疊加態 |
| 運算模式 | 序列式 | 平行（指數級算力） |
| 算力成長 | 線性 | 指數 |
| 比喻 | 開關 | 旋轉中的硬幣 |
| 應用潛力 | 一般計算 | 複雜模擬、密碼破解、最佳化 |

量子位元的三大特性：**疊加 (Superposition)**、**糾纏 (Entanglement)**、**干涉 (Interference)**。

## 2. Two-Level System (TLS) 與能階非等間距

現實中沒有完美的 TLS，一定有很多能階（如原子）。需從多能階中挑出兩個能階作為 |0⟩、|1⟩。

超導量子位元從古典 LC 電路演進：

| 類型 | 電路組成 | 能階特性 |
|---|---|---|
| 古典 LC 電路 | L + C | 連續能量 |
| 量子諧振器 | L + C | 離散等間距 ℏω |
| 超導量子位元 | **非線性電感** (約瑟夫森節) + C | **非等間距** → 可區分 |0⟩、|1⟩ |

非線性來源：約瑟夫森節（Josephson Junction）提供非線性電感，打破等間距，避免 |1⟩→|2⟩ 洩漏。

## 3. 約瑟夫森節 (Josephson Junction)

SIS 結構：Superconductor-Insulator-Superconductor。

- 兩層超導體（Al 或 Nb）+ 中間 nm 級氧化層
- 超導電流透過 **量子穿隧效應** 穿越絕緣層
- 提供非線性電感 \(L_J = \Phi_0/(2\pi I_c \cos\delta)\)

## 4. DiVincenzo 準則

一個可用的量子電腦必須滿足：

1. **可初始化**：能制備已知初始態（如 |0...0⟩）。
2. **相干操控**：量子態相干時間足夠長。
3. **通用量子閘**：單量子 + 雙量子閘集合可逼近任意么正。
4. **可測量**：能對 Qubit 做射影測量。
5. **可糾纏**：能產生多 Qubit 糾纏。
6. **可擴展**：能擴展到大量 Qubit（含互連/控制/測量）。

第 6 條是當前最大瓶頸：**wiring bottleneck**（控制線數量）與 **capacitive loading**。

## 6. 量子電腦架構的三大模組

1. **Qubit 層**：物理載體 + 電路拓撲（Transmon/Fluxonium/...）
2. **控制層**：微波/雷射/磁通偏置/直流偏置
3. **讀取層**：諧振器 + 放大器 + 數位化
4. **互連層**：Qubit-Qubit 耦合、Qubit-控制互連
5. **封裝/低溫層**：稀釋製冷機、Cryo-CMOS、線纜
