### 平台組成
- **資料層**：歷史行情、基本面、籌碼面
- **策略層**：策略開發、回測引擎
- **執行層**：券商 API 串接、下單執行
- **風控層**：停損停利、持倉管理、資金管理
- **監控層**：績效追蹤、警報通知

### 台灣市場特色
- **TEJ API**：台灣經濟新報，提供台股、期貨、選擇權數據
- **FinMind**：開源金融大數據 API
- **Shioaji**：永豐金 API，支援台股現貨與期貨
- **群益 API**：期貨下單與行情

### 部署架構
- Python 3.11+ 後端
- FastAPI / Streamlit 前端
- Docker 容器化
- PostgreSQL 資料庫
