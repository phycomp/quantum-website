### 策略特性
- **零預測、高機械化**：不預測市場方向，純機械執行
- **保守估計績效**：平均每分鐘獲利 30 點、每分鐘成交 2.3 筆
- **無保證金下單**：透過群益 API 進行模擬測試

### 技術需求
- Python 非同步控制（asyncio）
- 群益期貨 API 串接經驗
- Tick 數據即時處理
- 系統調優與參數最佳化

### 合作模式
- 策略邏輯已由 Python 撰寫完畢
- 徵求群益 API 串接合作夥伴
- 雙方簽署 NDA 與正式合作合約
- 分潤條款由合作夥伴主動提出
