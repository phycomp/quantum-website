### 資料獲取 API
| API | 市場 | 說明 |
|-----|------|------|
| **FinMind** | 台股/美股 | 台灣開源金融大數據 API，50+ 種數據 |
| **yfinance** | 全球 | Yahoo Finance，K 線、除權息、基本面 |
| **TuShare** | A 股 | 免費金融大數據接口 |

### 回測與策略框架
| 框架 | 用途 | 說明 |
|------|------|------|
| **backtrader** | 回測 | 最受歡迎的 Python 量化回測框架 |
| **vnpy** | 交易平台 | 從回測到實盤交易的完整框架 |
| **pyfolio** | 績效分析 | 夏普比率、最大回撤等分析圖表 |
| **TEJAPI** | 台灣市場 | 台灣經濟新報 API 範例庫 |

### 台灣券商 API 串接
- **永豐金 Shioaji**：REST API，支援 Tick 訂閱、下單、帳務查詢
- **群益期貨**：需自行開發 Gateway，繼承 BaseGateway
- **vnpy 整合**：將券商 API 包裝為 VN.PY 的 BaseGateway

### 開發流程
```
資料獲取 → 策略撰寫與回測 → 風險與績效評估 → 實盤部署
```

## 附錄：GitHub 量化開源項目完整清單

> 來源：~/量化/量化API.md（2026-11-11 整合）

在 GitHub 上，有許多優秀的開源量化分析 API、資料庫與交易框架。
以下為您整理 GitHub 上最熱門且實用的量化分析開源項目，分為資料獲取、回測分析框架與台灣市場專屬三大類：
1. 金融資料獲取 API
在進行量化分析前，首要任務是取得歷史與即時行情數據：
    • FinMind：台灣開源的金融大數據 API，可輕鬆獲取台股、美股、期權、財報及台股籌碼面等超過 50 種以上的數據。
    • yfinance：透過 Yahoo Finance API 下載歷史市值的熱門 Python 套件，適合美股與全球主流市場的 K 線、除權息與基本面數據獲取。
    • TuShare：免費的金融大數據接口（主要針對 A 股，但也包含部分全球數據），提供股票、基金、期貨及宏觀經濟數據。
2. 量化回測與策略框架
用於撰寫交易邏輯並驗證歷史勝率的核心工具：
    • backtrader：GitHub 上最受歡迎的 Python 量化回測框架之一，支援多商品回測、多指標分析，並內建詳細的圖表輸出。 [1]
    • vnpy：基於 Python 的開源量化交易平台開發框架，結合了底層接口與上層策略（如 CTP 期貨、證券 API 等），適合從回測一路對接到實盤交易。 [1]
    • pyfolio：專門用於投資組合性能和風險分析的套件，能一鍵生成夏普比率（Sharpe Ratio）、最大回撤（Max Drawdown）等量化人必備的分析圖表。 [1]
3. 台灣市場特定分析庫
    • TEJAPI_Python_Medium_Quant：台灣經濟新報（TEJ）維護的範例庫，包含使用 Python API 進行定期定額、技術分析、機器學習預測及籌碼分析的回測範例。 [1, 2]

如果您想深入探索，建議您可以直接到 GitHub 的 Market Data API Topics 頁面尋找最新的開源專案。 [1]
請問您接下來想找的是哪一個特定市場（如：台股、美股、加密貨幣）的 API？或是您有預計要使用特定的程式語言（如：Python, Node.js）嗎？

🔌 步驟 2：對接台灣券商 API 的實務路徑
由於 VN.PY 原生（官方核心庫）主要支援中國期貨 CTP、加密貨幣交易所（Binance, OKX）或互動經紀商（Interactive Brokers），對接台灣券商時，通常有兩種常見的技術解決方案：
方案 A：直接在 VN.PY 底層開發永豐金/群益的 Gateway（推薦專業開發者）
VN.PY 的架構高度模組化，所有券商都是透過繼承 BaseGateway 來實作。
    1. 您需要建立一個 ShioajiGateway 類別。
    2. 在裡面串接永豐金的 Shioaji API。
    3. 將永豐金回傳的市況（Quote）包裝成 VN.PY 的 TickData / BarData 餵給策略。
    4. 將策略的 buy()、sell() 轉譯為 shioaji.place_order() 發送給券商。
