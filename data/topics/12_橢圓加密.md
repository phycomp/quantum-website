## 核心概念

- **ECC**（Elliptic Curve Cryptography）：基於橢圓曲線離散對數問題（ECDLP）的公鑰加密體制
- 由 Koblitz 與 Miller 於 1985 年提出
- 數學基礎：橢圓曲線上點的 Abel 加法群運算
- 相較 RSA/DSA：相同安全等級下密鑰長度更短（256-bit ECC ≈ 3072-bit RSA）

## 橢圓曲線方程

```
y² = x³ + ax + b (mod p)
條件：4a³ + 27b² ≢ 0 (mod p)（確保曲線非奇異）
```

- `a, b`：曲線係數，決定曲線形狀
- `p`：大素數，定義有限域 𝔽ₚ
- `(x, y)`：曲線上的點

## 群運算：點加法

### 點加法公式
- **P ≠ Q**：斜率 m = (y₂ - y₁)(x₂ - x₁)⁻¹ mod p
- **P = Q（倍點）**：斜率 m = (3x₁² + a)(2y₁)⁻¹ mod p
- x₃ = m² - x₁ - x₂ (mod p)
- y₃ = m(x₁ - x₃) - y₁ (mod p)

### 標量乘法（Scalar Multiplication）
- k × P = P + P + ... + P（k 次點加）
- 使用雙倍-加法算法（Double-and-Add），時間複雜度 O(log k)

## 離散對數問題（ECDLP）

- **正向計算（容易）**：k × G = Q，O(log k)
- **逆向計算（困難）**：給定 G 和 Q，求 k，無已知多項式算法
- 最佳已知算法：Pollard's rho，O(√n)
- 對於 n ≈ 2²⁵⁶，需要 ≈ 2¹²⁸ 次運算
- ⚠️ **量子威脅**：Shor 算法可在 O((log n)³) 時間內破解

## 密鑰生成

- 私鑰：隨機整數 k ∈ [1, n-1]
- 公鑰：Q = k × G（基點 G 的標量乘法）
- 共享密鑰：Alice 計算 S = k_A × Q_B，Bob 計算 S = k_B × Q_A，兩者相同

## ECIES 加密方案

```
加密（Alice → Bob）：
1. 生成臨時密鑰對：r ∈ [1, n-1]，R = r × G
2. 計算共享密鑰：S = r × Q_B
3. 密鑰派生：k_enc || k_mac = KDF(x_S || R || Q_B)
4. 對稱加密：c = AES-GCM(k_enc, m)
5. 計算認證標籤：tag = MAC(k_mac, c || R)
6. 發送：(R, c, tag)

解密（Bob）：
1. 恢復共享密鑰：S' = k_B × R = S
2. 派生相同密鑰
3. 驗證 tag
4. 解密：m = AES-GCM⁻¹(k_enc, c)
```

## ECDSA 數位簽名

### 簽名生成
1. e = HASH(m)（取左邊 n 位）
2. 隨機選擇 d ∈ [1, n-1]，計算 (x₁, y₁) = d × G
3. r = x₁ mod n
4. s = d⁻¹(e + k·r) mod n
5. 輸出簽名：(r, s)

### 簽名驗證
1. 檢查 1 ≤ r, s ≤ n-1
2. e = HASH(m)，w = s⁻¹ mod n
3. u₁ = e·w mod n，u₂ = r·w mod n
4. 計算 (x₂, y₂) = u₁ × G + u₂ × Q
5. 驗證 r ≡ x₂ (mod n)

## ECC 特性

1. **高安全性**：ECDLP 難題，短密鑰長度提供同等安全
2. **短密鑰長度**：256-bit ECC ≈ 3072-bit RSA
3. **運算效率高**：橢圓曲線點運算相對簡單
4. **廣泛應用**：網路通信、電子商務、數字貨幣、PKI

## ECC 在 PKI 中的應用

- **初始化**：CA 選取橢圓曲線參數（p, a, b, G）
- **密鑰生成**：用戶生成密鑰對（私鑰 k，公鑰 Q = kG）
- **加密**：使用接收方公鑰加密，私鑰解密
- **簽名**：私鑰簽名，公鑰驗證
- **密鑰交換**：ECDH 協議建立共享密鑰

## ECC vs RSA 比較

| 特性 | ECC | RSA |
|------|-----|-----|
| 密鑰長度（同等安全） | 256-bit | 3072-bit |
| 簽章大小 | 64 B | 384 B |
| 加密速度 | 快 | 較慢 |
| 運算效率 | 高 | 中 |
| 抗量子性 | ❌ 否 | ❌ 否 |

## 量子威脅

- **Shor 算法**：可在 O((log n)³) 時間內破解 ECC
- 對於 256-bit ECC，約需 2048 邏輯量子比特
- 考慮糾錯後約需百萬級物理量子比特
- 遷移策略：混合模式（Hybrid Mode）
  - 共享密鑰 = KDF(ECC共享密鑰 || PQC共享密鑰)
  - 即使 PQC 被攻破，仍有 ECC 保護
  - 即使 ECC 被量子破解，仍有 PQC 保護
