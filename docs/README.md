# Quantum Website

## 功能
1. **搜尋網站**：本地內容搜尋 + 網頁搜尋。
2. **家目錄內容整合**：載入 ~/量子/PQC 與 ~/量子/橢圓加密 的 Markdown 檔案。
3. **網站開發**：Streamlit 多頁應用。
4. **本地測試**：`python tests/test_content_loader.py`。
5. **Social Media 上傳**：YouTube/TikTok/Instagram（見 UPLOAD_GUIDE）。

## 使用
```bash
cd /home/sam/quantum_website
streamlit run app.py
```

## 測試
```bash
cd /home/sam/quantum_website
python tests/test_content_loader.py
```
